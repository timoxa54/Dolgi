# Dolgi Project

A Python project for data parsing, scheduling, and optimization.

## Project Structure

```
Dolgi/
├── main.py          # Main entry point
├── parser.py        # Data parsing logic
├── schedule.py      # Schedule management
├── optimizer.py     # Optimization algorithms
├── models.py        # Mathematical models
├── requirements.txt # Python dependencies
└── README.md        # This file
```

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the main pipeline:
   ```bash
   python main.py
   ```

## Modules

- **parser.py**: Handles data parsing from various formats (JSON, CSV, etc.)
- **schedule.py**: Manages temporal scheduling and constraint validation
- **optimizer.py**: Implements optimization algorithms and heuristics
- **models.py**: Contains mathematical model definitions (linear, nonlinear)

## Dependencies

Required packages are listed in `requirements.txt`:
- numpy: Numerical computations
- scipy: Scientific computing
- pandas: Data manipulation
