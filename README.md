# 🎓 Dolgi — планировщик пересдач

**Dolgi** — локальное Python-приложение для автоматизации поиска и планирования пересдач академических задолженностей в БГПУ.

Программа анализирует зачётную книжку студента, определяет дисциплины с задолженностями, автоматически получает актуальное расписание преподавателей с официального сайта БГПУ и подбирает наиболее удобный набор дней и занятий для закрытия максимального количества долгов.

> ⚠️ Проект предназначен для личного использования. Авторизация выполняется под учётной записью самого пользователя. Пароль хранится локально в `.env` и не передаётся в Git-репозиторий.

## 📌 Что умеет программа

Программа проходит следующий путь:

```text
Зачётная книжка
       ↓

       ↓
```

Программа старается не просто найти как можно больше занятий, а построить **реально удобный план**:

* отсутствие пересечений по времени;
* предпочтение одного корпуса;
* минимальное количество переходов между корпусами;
* уменьшение времени ожидания между занятиями;
* уменьшение общей продолжительности дня.

# 🚀 Быстрый запуск

## 1. Требования

Для запуска необходимы:

* Windows 10/11;
* Python 3.12+;
* интернет;
* аккаунт студента БГПУ;
* установленный браузер Chromium для Playwright.

Рекомендуемая версия Python:

```text
Python 3.12
```

---

## 2. Клонирование проекта

```powershell
git clone https://github.com/timoxa54/Dolgi.git
cd Dolgi
```

---

## 3. Создание виртуального окружения

```powershell
python -m venv .venv
```

Активация:

```powershell
.venv\Scripts\Activate.ps1
```

Если PowerShell блокирует запуск:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

и повторно:

```powershell
.venv\Scripts\Activate.ps1
```

---

## 4. Установка зависимостей

```powershell
pip install -r requirements.txt
```

После установки Playwright необходимо установить браузер:

```powershell
playwright install chromium
```

---

## 5. Настройка авторизации

Создайте файл:

```text
.env
```

Внутри:

```env
BSPU_LOGIN=ваш_логин
BSPU_PASSWORD=ваш_пароль
```

Например:

```env
BSPU_LOGIN=student123
BSPU_PASSWORD=********
```

### 🔐 Важно

Файл `.env` **не должен попадать в Git**.

Он уже добавлен в `.gitignore`:

```gitignore
.env
.venv/
__pycache__/
*.pyc
.idea/
```

Поэтому реальные данные авторизации остаются только на компьютере пользователя.

# ▶️ Запуск

После настройки:

```powershell
python main.py
```

Программа автоматически:

1. откроет официальный сайт БГПУ;
2. перейдёт в личный кабинет;
3. выполнит авторизацию;
4. загрузит список задолженностей из сохранённой зачётной книжки;
5. найдёт преподавателей;
6. откроет расписание преподавателей;
7. соберёт доступные занятия;
8. сопоставит занятия с задолженностями;
9. запустит алгоритм оптимизации;
10. выведет итоговый план.

# 🧠 Как работает программа

## 1. Анализ зачётной книжки

Исходная информация берётся из HTML-файла зачётной книжки.

Парсер анализирует таблицы учебного плана и определяет:

* курс;
* дисциплину;
* вид контроля;
* оценку;
* преподавателя;
* количество часов;
* количество зачётных единиц.

Программа рассматривает только **2-й курс**.

Таблицы 3-го курса игнорируются.

---

## 2. Определение задолженности

Результат дисциплины классифицируется.

### Хорошие результаты

Следующие значения не считаются задолженностью:

```text
Зачет
Зачёт
Удовл
Удовлетворительно
Хорошо
Отлично
```

### Задолженности

```text
Н/я
Неявка
```

→ `Неявка`

```text
Неуд
Неудовлетворительно
```

→ `Неудовлетворительная оценка`

```text
Незачет
Незачёт
```

→ `Незачёт`

Пустая оценка:

```text
Оценка отсутствует
```

Если встретилось неизвестное значение:

```text
Проблемный результат: <значение>
```

Это сделано намеренно: программа не должна молча считать неизвестный результат хорошей оценкой или задолженностью.

# 🌐 Работа с сайтом БГПУ

Для получения расписания используется **браузерная автоматизация через Playwright**.

Программа не работает напрямую с внутренними API сайта.

Она действует так же, как обычный пользователь:

```text
Открыть сайт
    ↓
Личный кабинет
    ↓
Авторизация
    ↓
Расписание
    ↓
По преподавателям
    ↓
Поиск преподавателя
    ↓
Открытие страницы преподавателя
    ↓
Чтение расписания
```

Используемый официальный сайт:

```text
https://asu.bspu.ru/
```

Личный кабинет:

```text
https://www.asu.bspu.ru/WebApp/
```

Раздел расписания:

```text
https://asu.bspu.ru/WebApp/#/Rasp/List
```

# 🔐 Авторизация

Авторизация выполняется в `browser.py`.

Логин и пароль читаются из переменных окружения:

```python
login = os.getenv("BSPU_LOGIN")
password = os.getenv("BSPU_PASSWORD")
```

После открытия личного кабинета программа находит:

* поле логина;
* поле пароля;
* чекбокс согласия;
* кнопку `ВОЙТИ`.

Затем Playwright:

```text
заполняет логин
       ↓
заполняет пароль
       ↓
ставит галочку
       ↓
нажимает «ВОЙТИ»
       ↓
```
